# Photon layered assemblies - Phase 1 component set for the model home.
#
#   layer <material> <thickness_m> [fill <volume fraction>] [r <m2K/W>]
# Layers run from the "inside" face to the "outside" face:
#   walls/doors/windows: room -> exterior (interior walls: either side)
#   ceiling: room below -> attic above;  roof/gable: attic -> exterior
#   soffit: eave space -> exterior
# Sizes are actual modern standard sizes. Sources and verification status are
# in docs/DATA_REGISTER.md. Imperial sizes given in comments.

assembly ext_wall_2x4
  name "Exterior wall: painted 1/2 in gypsum, 2x4 @ 16 in o.c. with R-13 batt, 7/16 in OSB, vinyl siding"
  layer latex_paint 0.0001                     # two coats latex
  layer gypsum_board 0.0127                    # 1/2 in
  layer lumber_spf 0.0889 fill 0.094 r 2.29    # 2x4 (3-1/2 in deep) studs, 1-1/2 in every 16 in; R-13 batt
  layer osb 0.0111                             # 7/16 in wall sheathing
  layer pvc_vinyl 0.0011                       # 0.044 in vinyl siding
  leakage 0.0003
  source "Stud size: PS 20; spacing IRC R602.3(5); gypsum IRC R702.3.5; OSB IRC R602.3(3); R-13: IRC N1102.1.2 (verify)"
end

assembly int_wall_2x4

  leakage 0.0

end
